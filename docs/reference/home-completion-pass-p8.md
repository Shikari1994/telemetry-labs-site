# Home completion pass P8

Reference: https://labs.chaingpt.org/

## Goal

Complete the homepage composition before project-owned 3D assets exist. The page should already feel like one authored laboratory/editorial experience rather than a collection of independent landing-page blocks.

## Reference mapping

- ChainGPT hero -> Downhole Signal hero.
- Partners rail -> System Stack rail.
- Beyond Capital -> Beyond Measurement pinned state machine.
- Incubation/program content -> paired drilling data loops + indexed equipment stage.
- Portfolio -> Systems in the Field horizontal showcase.
- Media Presence -> Field Presence editorial grid.
- Testimonials -> Field Notes horizontal operating-principles deck (no fake endorsements).
- FAQ -> drilling telemetry FAQ.
- Latest News -> Latest Research technical-note grid.
- Interactive footer -> final signal-path media slot for future project-owned 3D/WebGL.

## Motion constraints

- One opening sequence after preloader.
- One Hero handoff timeline.
- One pinned timeline for Beyond Measurement.
- One horizontal scrub timeline for Systems in the Field.
- One horizontal scrub timeline for Field Notes.
- Section reveals use clipping/transform rather than fade-only animation.
- No perpetual rotations except intentional marquee-like loops.
- Mobile removes pin-heavy choreography and preserves native scrolling.

## Content constraints

No invented temperature/pressure/accuracy specifications and no invented client testimonials. Technical data on the homepage is demonstrative UI content until real product documentation is provided.
