## Motion quality rules
1. No independent decorative scroll controller inside a pinned narrative.
2. Avoid perpetual orbit/pulse/cursor animation outside marquees.
3. State changes use clipping, position and shared media-state changes rather than opacity-only fades.
4. Hero exit and next section entrance must visually hand off rather than behave as two unrelated blocks.
5. Desktop horizontal showcase must feel driven by page scroll; mobile must remain native and readable.
6. Reduced motion removes smooth scroll/pinning where needed but never hides content.

## Remaining parity gap
The largest remaining visual gap is media, not layout code: ChainGPT uses alpha-channel pre-rendered 3D hero/robot/coin assets and a static capsule. Our current device/chamber/BHA visuals are CSS media hosts and will be replaced later with original telemetry assets.
